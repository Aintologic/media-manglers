# Capabilities map

Every feature, screen and shared part of the Workbench, where each lives in the code, and which
features use it. A wave is not done until this map matches the code (AGENTS.md).

Code is named as `path::name`, relative to the repository root. `tests/test_capabilities_map.py`
checks that every name here still exists, so a rename or a deletion fails the suite until the map is
updated.

Features: **1** Package any video for AI, **2** Find my bug reports, **3** Watch the raw bin,
**4** AI Video Editor. Audio Mangler is not one of the four (Wave 11).
