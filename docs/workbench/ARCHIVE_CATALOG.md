# Archive Catalog

1. Choose **4 Archive Catalog**.
2. Choose the local source folder or configured catalog action.
3. Review the archive profile and output location.
4. Choose **Start review** only after the summary matches the intended action.

**Expected:** catalog, indexes, notes surfaces, and preparation manifests are
written locally. Restore or upload preparation is not an automatic upload.
