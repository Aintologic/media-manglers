# Transcript Only

1. Choose **2 Transcript Only** on Home.
2. Choose a local recording or folder.
3. Confirm language, audio-retention, and search choices in the profile.
4. Choose an output folder and review the summary.
5. Resolve dependency guidance if shown, then choose **Start review**.

**Expected:** timestamped transcripts and indexes are written locally. Literal
search results appear only when search terms were supplied.
