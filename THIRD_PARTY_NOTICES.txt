Optional tooling and services
-----------------------------

Media Manglers can use third-party tools and services that are not owned by
this repository.

Examples include:

- FFmpeg for media processing
- Whisper for local transcription and some local translation paths
- yt-dlp for supported remote media downloads and metadata retrieval
- Argos Translate for free local translation to non-English targets
- OpenAI for optional cloud translation when you configure an API key

Practical notes:

- These tools and services are separate from the GNU AGPL-3.0-or-later that
  covers this repository's code.
- OpenAI is optional and not bundled with the repo.
- OpenAI API usage depends on your own account, key, pricing, and service
  terms.
- Generated transcripts and translations should be reviewed before you rely on
  them for publication or downstream work.

----------------------------------

its own Python needs, from the Python Package Index, into your user folder
(%LOCALAPPDATA%\MediaManglers\addons). They come from their publishers, each
with its own licence file inside it; Media Manglers does not distribute them.
The exact files and checksums are in tools\installer\speech-lock.json:

- PyTorch (torch) 2.15.0 for the processor: BSD-3-Clause, with the licences of
  the software it includes (Apache-2.0, BSD-2-Clause, BSL-1.0, ISC, MIT, Zlib).
- numpy 2.5.4: BSD-3-Clause, with 0BSD, MIT, Zlib and CC0-1.0 parts.
- numba 0.68.1: BSD-2-Clause. llvmlite 0.50.0: BSD-2-Clause and Apache-2.0
  with the LLVM exception.
- tiktoken 0.14.0: MIT. regex 2026.11.9: Apache-2.0 and CNRI-Python.
- requests 2.34.2: Apache-2.0. urllib3 2.8.0: MIT. idna 3.20: BSD-3-Clause.
  charset-normalizer 3.5.2: MIT. certifi 2026.10.23: MPL-2.0.
- tqdm 4.70.1: MPL-2.0 and MIT. more-itertools 11.2.1: MIT.

Whisper models (base.en at first launch, any other only after you approve it)
are downloaded from OpenAI's model server into the Whisper model cache in your
user folder. Licence: MIT.

Replacing the LGPL libraries:

- The package is a folder, not a single file, so every Qt and FFmpeg library
  above is a separate file that you can replace with your own build.
- Replace the file of the same name in _internal\PySide6 (Qt and FFmpeg, and
  the plugins below it) or _internal\shiboken6 with a 64-bit Windows build of
  the same version series: Qt 6.11.x, or FFmpeg 7.1.x with avcodec-61,
  avformat-61, avutil-59, swresample-5 and swscale-8.
- The Workbench does not check these files when it starts. The build checks
  them only while the package is being made.
- You can also rebuild the whole package from this repository's source with
  tools\gui\Build-VideoManglerWorkbench.ps1.

Left out of the package: Qt Virtual Keyboard, which is offered only under the
GPL-3.0 and which the Workbench does not use, and Qt's OpenSSL TLS backend. Qt
uses Windows' own TLS without it.
